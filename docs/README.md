# Documentation

Public, user-facing documentation is published at
**[alforria.ai/docs](https://alforria.ai/docs/)**. Its source lives in the
website repository (`alforria-website`), under `content/docs/`.

This directory holds internal project documentation:

| Path | Contents |
| --- | --- |
| `plans/opencode-rust-port.md` | The port plan, pinned reference commit, and milestone table |
| `plans/improvement-plan.md` | Approved follow-up work |
| `plans/web-client.md` | The web client plan |
| `plans/web-ui.md` | Web UI notes |
| `plans/review-findings.md` | Review findings and decisions |
| `RELEASING.md` | Release checklist for binaries, GitHub notes, and the website |

Start with [README.md](../README.md) for install and development, and
[AGENTS.md](../AGENTS.md) for project conventions.

If a public docs page and this repository disagree, the source code and frozen
fixtures are authoritative. Please open an issue or a pull request so the page
can be corrected.
