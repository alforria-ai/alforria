# alforria

[![CI](https://github.com/alforria-ai/alforria/actions/workflows/ci.yml/badge.svg)](https://github.com/alforria-ai/alforria/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/alforria-ai/alforria?display_name=tag&sort=semver)](https://github.com/alforria-ai/alforria/releases)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**An AI coding agent for your terminal, in one Rust binary.** alforria reads
your repository, plans and writes code, runs tools, and manages its own
sessions. It runs on your machine and ships with a terminal UI, a local
HTTP/SSE server, and an embedded web client.

**[Documentation](https://alforria.ai/docs/)** · **[Install](https://alforria.ai/download.html)** ·
**[Releases](https://github.com/alforria-ai/alforria/releases)**

## Install

Linux, macOS, and WSL:

```sh
curl -fsSL https://raw.githubusercontent.com/alforria-ai/alforria/main/packaging/install.sh | sh
```

The installer resolves the latest release, verifies its SHA-256 checksum, and
installs `alforria` to `~/.local/bin`. Set `ALFORRIA_VERSION` to pin a release
or `ALFORRIA_INSTALL_DIR` to change the destination.

Release binaries are published for Linux x86_64, macOS x86_64/aarch64, and
Windows x86_64 on the
[releases page](https://github.com/alforria-ai/alforria/releases).

From source, with a Rust toolchain, C compiler, `pkg-config`, OpenSSL
development headers, and git:

```sh
cargo install --git https://github.com/alforria-ai/alforria --bin alforria
```

Verify the install:

```sh
alforria --version
```

## Quickstart

```sh
alforria auth login     # choose a provider and sign in
alforria models         # list available provider/model ids
alforria                # start the TUI
```

A one-shot, non-interactive run:

```sh
alforria run "summarize this repository and its test commands"
```

The local web client:

```sh
alforria web            # start the server and open the browser UI
```

Or run a headless server and connect another client:

```sh
alforria serve --port 4096
alforria attach http://localhost:4096
```

See the [quickstart](https://alforria.ai/docs/quickstart.html) for provider
setup, model selection, and the first session.

## What's inside

- **Terminal UI.** A ratatui chat view with sessions, subagents, diffs,
  permissions, questions, terminals, themes, and keyboard-first navigation.
- **Session engine.** Conversation history, compaction, cost accounting,
  Git-backed snapshots and revert, permissions, and subagent sessions.
- **14 built-in tools.** `bash`, `read`, `write`, `edit`, `apply_patch`,
  `glob`, `grep`, `task`, `webfetch`, `websearch`, `todowrite`, `question`,
  `skill`, and validation fallbacks. MCP servers can add more.
- **Named LLM adapters.** OpenAI Chat, OpenAI Responses, OpenAI-compatible
  Chat, Anthropic Messages, Gemini, and Bedrock Converse. LibertAI models work
  through the OpenAI-compatible endpoint.
- **Local server.** v1 and v2 HTTP APIs, SSE event streams, PTY websockets,
  OpenAPI documents at `/doc` and `/openapi.json`, and optional HTTP Basic
  auth. A password is generated by default when one is not configured.
- **Web client.** A multi-session supervision surface embedded in the binary
  and served at `/` by `alforria serve`.
- **Compatible configuration and storage.** alforria uses `opencode.json`,
  XDG config paths, and SQLite session storage. Compatibility is tested
  against frozen fixtures from the upstream project; user-facing surfaces use
  the alforria name.

## Development

```sh
cargo build                    # build the workspace
cargo fmt --all                # format
cargo fmt --all --check        # format check
cargo clippy --all-targets -- -D warnings
cargo nextest run              # tests (fallback: cargo test --all)
```

The embedded web client is built from `web/`:

```sh
cd web
bun install
bun run server                 # isolated server with a scripted model on :4697
bun run dev                    # vite on :4610, proxying the API
bun run check                  # prettier + tsc + vitest
bun run build && bun run pack   # rebuild crates/alforria-ui/assets/ui.tar.zst
```

### Workspace layout

| Path | Contents |
| --- | --- |
| `crates/alforria` | CLI entry point, command routing, TUI launch |
| `crates/alforria-core` | Session engine, tools, config, storage, bus, catalog |
| `crates/alforria-llm` | LLM protocols, streaming events, usage and cost, retries |
| `crates/alforria-schema` | Wire DTOs and events |
| `crates/alforria-server` | HTTP API, SSE, PTY websockets, auth |
| `crates/alforria-tui` | ratatui terminal UI |
| `crates/alforria-ui` | Embedded web UI bundle |
| `web/` | SolidJS web client source |
| `fixtures/` | Frozen compatibility fixtures (do not edit) |

## Security

alforria runs tools on your machine. Review permission rules before enabling
auto-approval, and do not expose an unauthenticated server to a network you do
not trust. See [SECURITY.md](SECURITY.md) for the threat model and how to
report vulnerabilities.
